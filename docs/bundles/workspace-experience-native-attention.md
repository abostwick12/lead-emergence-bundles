# Workspace Experience — native saved-work attention

Workspace Experience 0.4.0; Bundle Contract and UI Manifest Contract 1.0.
This is an implementation checkpoint. All six bundles remain NOT READY TO SHIP.

The portable attention contract defines thirteen record and nine task scopes,
current-authority requests, bounded metadata-only results, complete coverage
and bundle/priority counts, and exact original/task navigation. The host
implements the Attention navigation destination and existing declared Home
widget. Confirmed native layout controls determine whether the widget appears.

A direct native user needs Workspace Experience and each source's domain
capability. Executive assignment or source-sharing consent is not required for
the user's own native view, and no assistant permission follows from it.
An actual all-six OAuth connection is denied both native attention RPCs and
HTTP handlers; no shared attention MCP tool is advertised.

Current cues are paged 25 at a time, with source and priority filters. Complete
counts precede paging; offsets beyond 10,000 remain accessible. Saved blocks,
dates, priorities and open work explain the rules; they do not verify urgency,
source quality or completion. Parent and task cues may both appear. Comparison
dates apply to current records, not historical snapshots. Private source bodies,
profiles, drafts, proposals and provider accounts are not checked.

Host integration belongs in its owned codex2/bundle-experience-integration
branch, not this portable repository. Its thirty-three-file allowlist pins
feature revision b7c52e1f9f2a75beb3e701c5b303d95c7b7bc8fa.
See the host docs/architecture/workspace-native-attention.md and
docs/testing/workspace-attention-acceptance.md for implementation and final proof.

Source proof: typecheck, 147 tests in fourteen files, six plugin and six skill
validations. Native proof includes full 18,062-cue counts on the retained
fictional scale corpus, deep pages, current revocation, independent owner
controls, actual OAuth denial and confirmed Home-layout changes. This is not
a representative client-value result.

Remaining: connection/notification center, approved recurring lifecycle,

No new plugin app ID, provider connection, model runtime or marketplace
