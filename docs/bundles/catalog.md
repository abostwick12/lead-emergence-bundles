| Executive | Cross-bundle coordination | Evidence-linked attention brief from permitted task metadata |

| SOTF Bundle | Functional | Evidence-grounded transition hypothesis and one reviewable next move |

The bundle JSON files are generic product definitions. Dad is a first
composition configured in the authorized backend, not a branch or conditional
in this repository.

SOTF uses the logical bundle key `sotf_transition`. Its granted capabilities are
`career`, `daily_brief`, `memory`, `workspace_mcp`, and `agentic_workflows`.
`core_workspace` is a required host contract, not a granted bundle capability.
Protected Professional Context is outside this bundle.
