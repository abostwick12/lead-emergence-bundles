# Installed Sol quality rehearsal

Checkpoint: 2026-09-11

## Outcome

All six public-branch packages were installed together in Codex CLI 0.153.4 and
invoked in fresh, ephemeral, read-only gpt-5.6-sol sessions with the matching
fictional representative-pilot packet. The two separately configured Lead
Emergence MCP entries were disabled for every run. No client account, Workspace
entitlement, provider, internet research, save, message, schedule, publication
or trade was used.

The final artifacts passed every criterion that the text-only exercise could
actually observe:

The two unobserved Workspace checks require an interactive host: whether an

remains keyboard-usable. The output preserved exact supplied source identifiers,
refused to invent routes, and remained understandable without color, but those
facts are not substitutes for navigation and accessibility testing.

## Defects found and corrected

The first Executive attempt returned only an introductory sentence. A repeat
showed the selected 8,241-character entrypoint was being truncated by the
installed host. Executive 0.2.1 moved weekly outcomes, meeting availability and
delivery-schedule details into an on-demand reference while retaining the
always-needed authorization, evidence and user-control rules. The entrypoint is
now about 5.1 KB.

The next Executive run exposed a measurement defect: the fictional packet mixed
weekday deadlines with "in four days" but supplied no as-of time. Sol therefore
made an unsupported relative ordering. Executive 0.2.2 now requires an explicit
as-of time and named zone before comparing mixed date forms, and the reusable
packet supplies Wednesday, October 7, 2026 at 9:00 AM America/Chicago. The final
run then produced the correct sequence without a selected-skill truncation
warning.

Marketplace refresh adopted 0.2.1 and then 0.2.2 from the public feature ref.
At 0.2.1 the prior cache was absent and all four installed files matched the
refreshed marketplace snapshot by SHA-256. All four final 0.2.2 files also
matched its refreshed snapshot. A permanent packaging test now keeps every
always-loaded skill entrypoint at or below 7,500 bytes so conditional detail
must move to references before reaching the observed host boundary.

After the final run, all six temporary packages and the temporary marketplace
were removed. Codex reported zero installed Lead Emergence packages, the
marketplace root was absent, and the verified-empty package cache root was
removed. The 16 plugins present before this rehearsal remained installed.

## Evidence limits

- This is one synthetic final artifact per bundle, not repeated human use,
  measured time saved, an unaided first-use study or client acceptance.
- The artifact review was performed by the primary agent using the same model
  family, not by an independent evaluator.
- Every run emitted a host-level warning that global skill descriptions were
  compressed because many unrelated skills were enabled. No final selected
  Lead Emergence entrypoint was truncated.
- The final Executive session also performed the host's normal local-memory
  lookup. No memory-derived claim appeared in the artifact, but that run is not
  described as perfectly isolated.
- Text output cannot prove installed ChatGPT presentation, real navigation,
  responsive UI, keyboard behavior, provider state, server authorization,
  recovery or production operation.

The correct conclusion is a bounded installed-Codex output-quality pass with
host limitations. Representative pilots, the ChatGPT install surface and
deployed acceptance remain open release gates.
