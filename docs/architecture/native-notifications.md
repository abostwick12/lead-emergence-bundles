# Native notifications: current conditions, private choices

P14 adds a host-native current-condition inbox, not a historical event log,
scheduled delivery system or model-facing cross-domain notification tool.

The portable notifications.ts contract declares eight supported types, exact
reviewed changes, complete page metadata and saved-choice receipts. UI manifests
contribute these types only through their actual implemented source capabilities.
Ministry's date cue is bound to research, not an unimplemented teaching workflow.
Investor's cue is explicitly a recorded concern, not a live material market alert.
Executive contributions separately require coordination, brief or review access.

The host owns authorization, database evaluation, persistence and UI. Native owner
identity is server-derived. A source must remain admitted on every read/write,
including receipt replay. Private tables hold per-type mute and per-condition
read/dismiss/24-hour snooze choices; none belong in Git or a model context.

Current source conditions disappear when resolved or inaccessible. Condition
fingerprints exclude routine title/activity changes. Changed dates, date
categories or recorded concerns can reopen unread; returning unchanged conditions
retain their earlier acknowledgement. Dates follow a supported saved owner time
zone, with UTC fallback. Snooze expiry is checked on a later page visit/refresh,
not delivered through a background worker.

Bulk read touches only the reviewed visible page. Exact request IDs and expected
choice versions make retries safe and reject stale tabs. Sources themselves are
never completed, sent, published, refreshed or modified by notification choices.

The public host branch imports a pinned 35-file allowlist, including the new
contract. This is not permission to publish plugin listings, merge main, deploy
a hosted migration, connect a provider or claim installed-host acceptance.

Remaining client-release work includes shared crash recovery, representative
source/value evaluation, installed-host acceptance, approved scheduled delivery,
and deployed privacy, rollback, retention and entitlement/payment gates.
