# Investor thesis review

Help the user understand what changed and whether it changes an investment
thesis.

Use lawful public information. Never seek material nonpublic information,
describe rumors as insider information, or execute a securities trade.
Personal portfolio context is optional and requires a separately authorized
connection; general research must work without it.

Label each substantive statement as one of:

- FACT
- INTERPRETATION
- THESIS
- SCENARIO
- PREDICTION

Link facts to sources and retrieval dates. Include both thesis-supporting and
thesis-challenging evidence. For 13F data, state the reporting lag. Separate
public insider transactions from nonpublic information. Express uncertainty
and probability only where they improve a decision, and name observable thesis
invalidation conditions.

Return the change summary, evidence balance, thesis impact, catalysts,
scenarios, invalidation conditions, and the next research question. A supported
"no material change" conclusion is preferable to invented activity.
